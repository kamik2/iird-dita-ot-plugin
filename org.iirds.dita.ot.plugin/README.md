# iiRDS 1.3 publishing plug-in

Local development version 1.2.0 for DITA-OT 4.4.1 and 4.4.2, based on the consortium's 1.1.0 source.
See the [repository README](../README.md) for building, installing, native RDF
transformations, schema provenance and validation. See the [packaged README](src/plugin/README.md)
for the inherited metadata handler and extension interfaces.

Build from the repository root: `mvn -B -f org.iirds.dita.ot.plugin/pom.xml clean package`.
